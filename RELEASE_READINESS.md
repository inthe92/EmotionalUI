# EmotionalUI v0.1.0-preview.1 — release scope and checks

Target: RG353V, observed dArkOS (Debian13, kernel5.10.226, glibc2.41). Other firmware/devices are not certified. Software is default, FemtoVG/Mali-G52 experimental. Immediate swap is not the default. No sustained30/60FPS claim.

The public preview is isolated from the later Daily Driver development. It cannot launch games or change system controls. It does not install drivers, alter boot or replace EmulationStation. The native loader must resolve existing device libraries before graphics starts.

- Original room: owner declaration recorded in `assets/scenes/daycycle/selected-room-v1/PROVENANCE.md`; original reference with commercial covers is not bundled. No independent title-of-rights certification is claimed.
- Notices: pinned Cargo inventory, received upstream texts, original MIT declarations/README and separately identified canonical MIT supplements for the two upstream packages lacking a license file. No invented copyright notice.
- Privacy: existing source/history and binary review retained. No personal location, credentials, SSH diagnostics, ROMs, BIOS or commercial covers in the source allowlist/package. Normal authorized Git author metadata remains.
- Packaging: explicit hash-pinned sources, both ARM64 ELFs, corresponding source archive, own-files installer and four graphical Ports entries. ZIP extraction must preserve the hidden package folder directly inside Ports.
- Recovery: transient PID1 trial unit, external return to EmulationStation and15-minute safety limit. Restore/uninstall remove only verified owned installation files; personal data stay separate.
- Regression:27 focused distribution/installer tests previously passed. Cup correction:3 raster tests and5 focused ambient checks passed; four paired640×480 captures keep changes confined to the window/cup boundary. Seven original paintings hash-identical.
- Physical evidence: installed software and GPU preview sessions observed on the same RG353V; the owner confirmed appearance/motion and audible audio after a volume adjustment. These facts do not certify a different ZIP. The exact release artifact must pass supervised installation/open/return/restore/uninstall before publication; its results and SHA are recorded in the GitHub release notes.

Known limits: variable frame pacing, renderer text/line-break differences, uncertified analog/system controls and no game launching in trial. Installation in ten minutes is a goal, not a measured claim. Release authorization and PUBLIC visibility authorization were both explicitly granted; no further editorial approval is required. Reddit remains unposted.
