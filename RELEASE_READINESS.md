# Preparación de distribución · no es una release pública

Versión de trabajo 0.2.0; no estable. Candidato privado con ELF ARM64, manifiesto/hash y archivos propios. No se ha publicado, subido a GitHub ni enviado a Reddit. El objetivo de diez minutos requiere una prueba posterior con personas sin conocimientos Linux.

Disponible: compilación bloqueada por versiones, pruebas, modo vista previa real, Atlas experimental opt-in, scripts conservadores y separación de datos personales. No se reconfiguran ROMs, emuladores ni mandos automáticamente; el acceso físico desde el menú dArkOS sigue pendiente de verificar.

Bloqueos de publicación:

- Validar en RG353V la revisión concreta de dArkOS, DRM/orientación, controles, audio y retorno a EmulationStation. Ningún proceso sintético lo sustituye.
- Resolver derechos de redistribución de la referencia que originó el fondo adaptado. La posesión de una imagen aportada no demuestra todos los derechos; no se afirma exclusividad ni licencia pública definitiva de ese recurso.
- Completar inventario/notices y condiciones de distribución de dependencias transitivas, junto con la fuente correspondiente aplicable. GPL-3.0-only existente se conserva; DejaVu y CC0 del piano mantienen sus condiciones separadas.
- Revisar fichas/selecciones con personas y documentar aprobaciones auténticas antes del canal estable.
- Consolidar una lista pública de archivos sin logs privados, revisar identidad Git del autor y establecer canal de seguridad. No se inventa una identidad para crear el primer commit.

El paquete no es una imagen del sistema. install-main está bloqueado; no se ofrece una instalación principal falsa. Los scripts requieren Python y reconocimientos de cesión/recuperación; todavía no cumplen una experiencia para principiantes sin terminal. No se garantiza actualmente una restauración visible tras fallo de DRM.
